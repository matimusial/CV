# Mateusz Musiał | Fullstack Developer Portfolio

[Download CV](./public/documents/Mateusz-Musial-CV.pdf)

## Tech stack

`Next.js` `React` `TypeScript` `Tailwind CSS` `typesafe-i18n` `Lucide React`

The project uses the Next.js App Router, strict TypeScript, React Compiler and a component-based structure divided into sections, layouts, modals and common UI.

## Run locally

Requires Node.js `20.9.0` or newer.

```bash
git clone https://github.com/matimusial/CV.git
cd CV
npm install
npm run dev
```
